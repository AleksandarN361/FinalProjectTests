# SemosProject
QA mini project from Semos Software Tester Academy.

This project contains automated tests for a shopping website. The testing is focused on validating core funcionalities across two different versions of the web application and tracking UI bugs.

TECHNOLOGIES USED:
* C#
* Selenium WebDriver
* NUnit

IDE:
* Microsoft Visual Studio

BROWSER SUPPORT:
* Google Chrome

TEST COVERAGE:
* 80 manual test cases with scenarios (documented in Azure DevOps)
* 69 automated test cases (implemented in code)

DESIGN:
* Page Object Model (POM) design pattern
* Custom methods for reusability and maintainability
